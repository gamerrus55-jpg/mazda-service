# Моя Mazda

Личное приложение для ТО: Mazda Axela (BM) 2018, 1.5 SkyActiv-G, автомат, передний привод.

- **Регламент** — 14 пунктов (масло, фильтры, свечи, жидкости, ремень, тормоза, подвеска…), у каждого своя картинка, статус «в норме / скоро / пора» и сколько осталось по км и по времени.
- **Подробно** — что делать, какая жидкость и объём, артикулы (нажми — скопируется), советы, история замен.
- **Журнал** — все замены и ремонты с датой, пробегом и ценой, расходы за год.
- **Напоминания** — раз в день проверка регламента и уведомление, если что-то пора делать или давно не обновлялся пробег.
- **Условия** — обычные или тяжёлые (морозы, пробки, короткие поездки): интервалы подстраиваются.

## Обновления
Каждый push в `main` собирает новый APK. Приложение само сообщает о новой версии.
Последняя сборка: https://github.com/gamerrus55-jpg/mazda-service/releases/latest/download/MazdaService.apk

## Поменять регламент
`app/src/main/java/ru/my/mazda/Regulation.kt` — интервалы, жидкости, объёмы и артикулы.
Картинки узлов — `app/src/main/res/drawable/pic_*.xml`.
